# Tiger Protection Project 🐯

A dynamic website created to raise awareness for wild tiger population and support their natural habitats. 

## 🚀 Features
- **Modern Flexbox Design:** Completely responsive layout with a dark theme.
- **Dynamic Donation Panel:** Interactive counter allowing users to choose a donation amount between $1 and $20.
- **Toggleable Info Modals:** Users can dynamically read "Who we are" and "How we protect" sections without page reloads.

## 🛠️ Tech Stack
- HTML5
- CSS3 (with Custom Properties and Flexbox)
- Vanilla JavaScript
